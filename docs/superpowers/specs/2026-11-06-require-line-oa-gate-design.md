# เอกสารออกแบบ: บังคับเปิดผ่านแอป LINE และแอดเพื่อน LINE OA ก่อนสะสมแสตมป์ (Strict LINE OA Gate)

- **วันที่:** 2026-11-06
- **หน่วยงาน:** อุทยานเทคโนโลยี มจพ. (KMUTNB Techno Park)
- **ขนาดงาน:** การปรับปรุงขนาดเล็ก (Small Change)

---

## 1. เจตนาและที่มา (Intent & Why)
ในวันงานจริง นักเรียนบางส่วนสแกนป้าย QR Code ประจำฐานด้วยกล้องมือถือโดยยังไม่ได้แอดเพื่อน LINE OA (`@096ilctj`) หรือเปิดค้างอยู่ในเบราว์เซอร์ชั่วคราวของกล้อง เมื่อหน้าเว็บหลุดหรือปิดไปแล้วย้อนกลับเข้ามาใหม่ (หรือค่อยแอด LINE OA ทีหลัง) รหัสผู้ใช้เปลี่ยนเป็นคนละเซสชัน ทำให้แสตมป์ที่สะสมไว้หายไป จึงต้องกั้นให้นักเรียนเปิดผ่านแอป LINE และแอดเพื่อน LINE OA ให้เรียบร้อยก่อนเริ่มสะสมแสตมป์

## 2. เป้าหมาย ขอบเขตที่ไม่ทำ และสิ่งที่ต้องหลีกเลี่ยง (Goals, Non-Goals, Anti-Goals)
- **เป้าหมาย (Goals):**
  - ป้องกันไม่ให้นักเรียนสะสมแต้มในเบราว์เซอร์ชั่วคราวนอกแอป LINE
  - บังคับให้แอดเพื่อน LINE OA (`@096ilctj`) ก่อนเริ่มสะสมแสตมป์ เพื่อให้นักเรียนมีห้องแชท LINE OA สำหรับกดกลับเข้ามาดูบัตรสะสมแต้มได้ตลอดเวลาแม้เผลอปิดหน้าจอ
  - รักษารหัสฐาน (`?booth=...`) ที่นักเรียนเพิ่งสแกนไว้ เพื่อให้ประทับตราฐานแรกได้ทันทีหลังจากแอดเพื่อนเสร็จโดยไม่ต้องเดินไปสแกนป้ายซ้ำ
- **สิ่งที่ไม่ทำ (Non-Goals):**
  - ไม่ทำระบบกู้คืนแต้มย้อนหลังของคนที่หลุดไปแล้วก่อนหน้านี้
- **สิ่งที่ต้องหลีกเลี่ยง (Anti-Goals):**
  - ห้าม fallback ไปสร้างรหัสผู้ใช้จำลอง (`DEMO-U...`) อัตโนมัติเมื่อเปิดใช้งานจริงที่มี `LIFF_ID` แล้ว (ยกเว้นเปิดโหมดทดสอบ `?demo=1`)

## 3. ข้อจำกัด (Constraints)
- ต้องทำงานได้ทันทีกับป้าย QR Code ที่พิมพ์ติดหน้าฐานไปแล้ว (`https://liff.line.me/2012153981-eWRVDFrg?booth=...`) โดยไม่ต้องพิมพ์ป้าย QR ใหม่

## 4. แนวทางที่พิจารณา (Approaches)
1. **แนวทางที่ 1: ผูกแต้มด้วยชื่อเล่น + เลขท้ายเบอร์โทร 4 ตัว**
   - *ข้อแลกเปลี่ยน:* กู้แต้มข้ามเบราว์เซอร์ได้ แต่ไม่ได้บังคับให้นักเรียนแอด LINE OA ตั้งแต่วินาทีแรก
2. **แนวทางที่ 2 (แนวทางที่เลือก): บังคับเปิดในแอป LINE และแอดเพื่อน LINE OA (`@096ilctj`) ก่อนสแกน (Strict LINE Gate)**
   - *ข้อแลกเปลี่ยน:* นักเรียนต้องกดแอดเพื่อน LINE OA และเปิดในแอป LINE ก่อนจึงจะสะสมแต้มได้ แต่แก้ปัญหาหน้าเว็บหลุดแล้วหาทางกลับเข้าไม่ได้ และผูกแต้มกับบัญชี LINE ถาวรตั้งแต่วินาทีแรก
3. **แนวทางที่ 3: ลูกผสม (ชวนเข้า LINE OA + ตั้งรหัสชื่อเล่นสำรอง)**
   - *ข้อแลกเปลี่ยน:* มีขั้นตอนกรอกรหัสสำรองเพิ่มขึ้นมา ซึ่งไม่จำเป็นหากบังคับเข้าผ่าน LINE OA ตั้งแต่ต้นแล้ว

## 5. รายละเอียดการทำงานที่ตกลงกัน (Decided How)
1. **ปิดการ Fallback เข้าโหมดจำลองบนหน้างานจริง:** ใน `public/app.js` หากตั้งค่า `liffId` แล้วและไม่ได้ระบุ `?demo=1` ระบบจะไม่เรียก `getOrCreateDemoUser()` เด็ดขาด
2. **กั้นเมื่อเปิดนอกแอป LINE (`!liff.isInClient()`):** หากสแกนผ่านกล้องมือถือแล้วเปิดค้างใน Safari/Chrome หรือ WebView ภายนอก จะแสดงหน้าจอกั้นพร้อมปุ่มกดเปิดเข้าแอป LINE โดยตรง (`https://line.me/R/app/<LIFF_ID>?booth=...`)
3. **กั้นเมื่อยังไม่ได้แอดเพื่อน LINE OA (`@096ilctj`):** เมื่อเปิดในแอป LINE แล้ว จะตรวจสอบ `liff.getFriendship()` หาก `friendFlag === false` จะแสดงหน้าจอกั้นให้กดปุ่ม **"➕ กดเพิ่มเพื่อน LINE OA (@096ilctj)"** ก่อน และเมื่อกลับมาที่หน้าจอ (หรือกดปุ่มยืนยันว่าเพิ่มเพื่อนแล้ว) ระบบจะเช็กซ้ำและปลดล็อกหน้าบัตรสะสมแสตมป์พร้อมประทับตราฐานที่สแกนค้างไว้ให้ทันที

## 6. สิ่งที่ผู้พัฒนาจัดการให้ (Left to the Builder)
- เก็บรหัสฐานที่สแกนเข้ามา (`?booth=...`) ไว้ใน `sessionStorage` / `localStorage` ชั่วคราวระหว่างที่นักเรียนไปกดแอดเพื่อน เพื่อให้พอกลับมาแล้วประทับตราฐานนั้นได้อัตโนมัติ
- ดึงชื่อโปรไฟล์จากทั้ง `liff.getProfile()` และ `liff.getDecodedIDToken()` เพื่อให้แสดงชื่อ LINE จริงของนักเรียนได้ครบถ้วน
- ตรวจสอบสถานะเพื่อนซ้ำอัตโนมัติเมื่อหน้าจอกลับมาแสดงผล (`visibilitychange` / `focus`) เพื่อลดการกดปุ่มซ้ำซ้อน

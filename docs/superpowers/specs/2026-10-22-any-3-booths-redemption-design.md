# เอกสารออกแบบการปรับเกณฑ์แลกรางวัล: สะสมครบ 3 ฐานจากฐานทั้งหมด (Any 3 Booths Redemption)

- **วันที่:** 2026-10-22
- **ประเภทงาน:** การปรับปรุงขนาดเล็ก (Small Change)

## 1. เจตนาและที่มา (Intent & Why)
ในงาน Open House มีฐานกิจกรรมหลายฐาน แต่ต้องการให้นักเรียนสามารถเลือกเข้าชมและสแกนสะสมแสตมป์เพียง **3 ฐานใดก็ได้** จากฐานทั้งหมดที่เปิดอยู่ เพื่อปลดล็อกการกรอกข้อมูลสั้นๆ และแลกรับของรางวัลได้ทันทีโดยไม่ต้องเดินครบทุกฐาน

## 2. เป้าหมาย ขอบเขตที่ไม่ทำ และสิ่งที่ต้องหลีกเลี่ยง (Goals, Non-Goals, Anti-Goals)
- **Goals:** เพิ่มค่าตั้งต้น `required_stamps = 3` (แก้ไขตัวเลขได้ในหน้า Admin), ปรับการคำนวณผ่านเกณฑ์ (`isCompleted`) เป็น `stampedCount >= requiredStamps`, แสดงความคืบหน้าในหน้าจอนักเรียนเป็น `X / 3 ฐาน (จากทั้งหมด N ฐาน)` และอนุญาตให้นักเรียนสแกนฐานที่ 4, 5 ต่อได้แม้ครบเกณฑ์แล้ว
- **Non-Goals:** ไม่กำหนดฐานบังคับ (ทุกฐานมีศักดิ์เท่ากัน เลือกเข้าฐานใดก็ได้)
- **Anti-Goals:** ห้ามซ่อนรายชื่อฐานที่เหลือ (ต้องแสดงฐานทั้งหมดเพื่อให้นักเรียนเห็นว่ามีฐานอะไรให้เดินไปชมบ้าง) และห้ามล็อกไม่ให้สแกนฐานอื่นต่อหลังจากครบ 3 ฐาน

## 3. ข้อจำกัด (Constraints)
- หากจำนวนฐานที่เปิดใช้งานจริง (`activeBooths`) มีน้อยกว่าค่า `required_stamps` (เช่น เปิดแค่ 2 ฐาน) ระบบจะยึดตามจำนวนฐานที่เปิดอยู่จริงโดยอัตโนมัติ (`Math.min(required_stamps, totalBooths)`) เพื่อไม่ให้เกิดกรณีที่ไม่มีใครเก็บครบได้

## 4. แนวทางที่พิจารณาและแนวทางที่เลือก (Approaches)
- **แนวทางที่ 1 (เลือกใช้):** แสดงรายการฐานทั้งหมดในหน้าการ์ดนักเรียนควบคู่กับแถบความคืบหน้า `X / 3 ฐาน` — ช่วยให้นักเรียนเห็นรายชื่อฐานทั้งหมดในงานและเลือกเข้า 3 ฐานที่สนใจได้ทันที (แลกกับการที่หน้าจอมีรายการการ์ดตามจำนวนฐานทั้งหมด)
- **แนวทางที่ 2:** แสดงช่องว่างแค่ 3 ช่อง — หน้าจอกระชับแต่ทำให้นักเรียนไม่เห็นว่าในงานมีฐานอะไรให้ไปเดินชมบ้าง

## 5. รายละเอียดการปรับปรุง (How It Works & Builder Calls)
- **ฐานข้อมูล (`src/db.js`):** เพิ่มคีย์ `required_stamps: '3'` ใน `DEFAULT_SETTINGS` คำนวณ `requiredStamps = totalBooths > 0 ? Math.min(Number(settings.required_stamps) || 3, totalBooths) : 0` และ `isCompleted = requiredStamps > 0 && stampedCount >= requiredStamps` ทั้งใน `getParticipantState`, `getAdminOverview`, และ `exportCsv`
- **หน้าจอนักเรียน (`public/app.js`):** แสดงความคืบหน้าเป็น `สะสมแล้ว X / 3 ฐาน (เลือกเข้าฐานใดก็ได้)` และคำนวณหลอดความคืบหน้าเทียบกับ `requiredStamps`
- **หน้าเจ้าหน้าที่ (`public/admin.html`, `public/admin.js`):** เพิ่มช่องตั้งค่า "จำนวนแสตมป์ขั้นต่ำเพื่อแลกรางวัล (ฐาน)" ในหน้า Admin
